## What Is Imposition Wizard

Imposition Wizard arranges PDF pages onto sheets before a short print. Imposition Wizard booklet layout is for a booklet or a thin book: page one meets the right neighbor when the sheet is folded. Imposition Wizard signature sheet splits a longer file into groups of sheets so each group can be folded on its own. A school zine, a home recipe booklet, or a small shop flyer run is the right scale.

Imposition Wizard crop marks tell you where the trim goes. Imposition Wizard n-up grid is the other common job, when you are not folding a booklet but placing several cards or handouts on one sheet. Imposition Wizard creep shift matters only when the stack is thick enough that inner pages would otherwise stick out. For a thin homework booklet you can leave creep alone and still check the marks.

Preview before you commit paper. Confirm Imposition Wizard booklet layout page order with a numbered test, set Imposition Wizard crop marks, and use Imposition Wizard signature sheet if the file is more than one fold group. Switch to Imposition Wizard n-up grid for cards. Add Imposition Wizard creep shift only after you know the paper is thick.
